# Belief-Aware Pushing Website

Static project page for:

**Learning Belief States for Legged Non-Prehensile Manipulation of Large Objects**

The page reuses the academic project-page structure from `quadrupedpushing-cr2.github.io` and incorporates diagrams, videos, and visual result assets from `anonymous-loco-manipulation.github.io`.

Open `index.html` directly in a browser, or serve the folder with any static web server.
